# Python Forge (графический движок)

```Графический движок``` (иногда его называют "рендерер" или "визуализатор") - это программный инструмент, главная задача которого - ```рендеринг```, то есть преобразование данных (моделей, текстур, освещения) в видимое на экране изображение. Он может существовать как самостоятельный продукт или быть частью более крупного инструмента, например, игрового движка.
